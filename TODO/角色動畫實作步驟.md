# 角色動畫實作步驟

Last updated: 2026-05-11

這份筆記記錄 Pink_Monster 的角色動畫實作方式。這個專案使用 Cocos Creator 2.4.8，角色素材是多張橫向 sprite sheet，每張圖代表一個動作。

## 素材規則

- 每個角色動作是一張獨立圖片。
- 每格大小都是 `32 x 32`。
- 檔名最後的數字代表該動作有幾格。

例如：

```text
Pink_Monster_Idle_4.png  = Idle 動作，4 格，圖片大小 128 x 32
Pink_Monster_Run_6.png   = Run 動作，6 格，圖片大小 192 x 32
Pink_Monster_Jump_8.png  = Jump 動作，8 格，圖片大小 256 x 32
```

## 圖片匯入設定

每張角色動作圖片都建議設定：

```text
Filter Mode: Point
Trim Type: None
Wrap Mode: Clamp
Gen Mipmaps: 不勾
```

設定完要按右上角的 `Apply`。

重點：

- `Filter Mode` 要設成 `Point`，放大後才會是清楚的 pixel art。
- `Trim Type` 要設成 `None`，避免 Cocos 自動裁掉透明邊界，導致程式切 `32 x 32` 格子時位置錯掉。
- 只設定 Idle 不夠，Run、Jump、Attack、Hurt、Death 等每張圖都要設定。

## 不使用 Sprite Editor 切圖

一開始嘗試用 Sprite Editor，但 Cocos Creator 2.4.8 的 Sprite Editor 主要是在調 `Border / Trim`，不是很適合直接把這種橫向 sprite sheet 切成多個 animation frame。

所以目前採用程式切圖：

- 用 `SpriteSheetAnimator.js` 讀一張 texture。
- 依照 `Frame Width`、`Frame Height`、`Frame Count` 自動切出多個 `SpriteFrame`。
- 用 `Frames Per Second` 控制播放速度。

## 需要的 Script

目前新增了兩個 script：

```text
assets/scripts/SpriteSheetAnimator.js
assets/scripts/PinkMonsterController.js
```

### SpriteSheetAnimator

用途：

- 從一張橫向 sprite sheet 自動切出 frame。
- 播放動畫。
- 支援切換不同動作。

主要設定：

```text
Texture: 要播放的動作圖片
Frame Width: 32
Frame Height: 32
Frame Count: 依照檔名最後數字設定
Frames Per Second: 動畫速度
Loop: 是否循環播放
Play On Load: 進場後是否自動播放
```

Pink_Monster Idle 的設定：

```text
Texture: Pink_Monster_Idle_4
Frame Width: 32
Frame Height: 32
Frame Count: 4
Frames Per Second: 8
Loop: 勾
Play On Load: 勾
```

### PinkMonsterController

用途：

- 測試 Pink_Monster 不同動作。
- 用鍵盤切換動畫。
- 目前只測動畫，還沒有正式角色位移與物理。

需要拖入的 texture：

```text
Idle Texture: Pink_Monster_Idle_4
Run Texture: Pink_Monster_Run_6
Jump Texture: Pink_Monster_Jump_8
Attack Texture: Pink_Monster_Attack1_4
Hurt Texture: Pink_Monster_Hurt_4
Death Texture: Pink_Monster_Death_8
```

測試按鍵：

```text
A / Left: 往左跑步動畫
D / Right: 往右跑步動畫
Space / W / Up: 跳躍動畫
J: 攻擊動畫
H: 受傷動畫
K: 死亡動畫
放開左右鍵: 回 Idle
```

目前 `Death` 設定為不循環播放，播完會停在最後一格。這符合死亡狀態的常見做法。

## 在場景中建立角色

1. 在場景中建立一個角色節點，例如：

```text
Pink_Monster
  - sprite
```

2. 選下面真正顯示圖片的 `sprite` node。

3. 加上 `Sprite` component。

4. 加上 `SpriteSheetAnimator` component。

5. 在 `SpriteSheetAnimator` 裡先設定 Idle：

```text
Texture: Pink_Monster_Idle_4
Frame Width: 32
Frame Height: 32
Frame Count: 4
Frames Per Second: 8
Loop: 勾
Play On Load: 勾
```

6. 如果角色太小，調整 `sprite` node 的 Scale：

```text
Scale X: 3 或 4
Scale Y: 3 或 4
```

7. 加上 `PinkMonsterController` component。

8. 把各動作圖片拖進對應欄位。

9. 按 Play 測試動畫切換。

## 如果 Add Component 找不到 Script

如果新增 script 後，Cocos 裡找不到 component：

1. 先按：

```text
Project > Refresh
```

2. 確認 `assets/scripts` 底下有對應 `.js` 與 `.js.meta`。

3. 如果還是沒有，關掉 Cocos Creator 後重新開專案。

這次遇到的狀況是 `SpriteSheetAnimator.js` 一開始沒有 `.meta`，所以 Cocos 沒有把它匯入成 asset。補上 `.meta` 後 Refresh 才正常出現。

## 套用到其他角色

之後要做 Owlet_Monster 或 Dude_Monster，可以沿用同一套方式：

1. 確認每張動作圖都是橫向 sprite sheet。
2. 確認每格是 `32 x 32`。
3. 每張圖設定：

```text
Filter Mode: Point
Trim Type: None
```

4. 建立角色 node。
5. 加上 `SpriteSheetAnimator`。
6. 如果要測試鍵盤切換，可以複製 `PinkMonsterController.js` 改成新角色的 controller。

## 後續可改進

- 把 `PinkMonsterController` 改成正式角色控制器，加入水平移動、跳躍、重力與碰撞。
- 增加 `isDead`、`isAttacking` 等狀態，避免死亡或攻擊被其他動畫打斷。
- 把角色動畫資料整理成共用格式，讓不同角色可以共用同一個 controller。
- 之後 Mini Game 2 需要兩個玩家時，可以讓 Player 1 / Player 2 使用同一套 animator，只換 texture 或角色素材。

## 加入實際移動與動畫切換

`PinkMonsterController.js` 目前已經不是單純動畫測試，而是有簡單角色移動：

```text
A / Left: 往左移動，播放 Run
D / Right: 往右移動，播放 Run
Space / W / Up: 跳躍，播放 Jump
沒有左右輸入且在地面上: 播放 Idle
J: 播放 Attack
H: 播放 Hurt
K: 播放 Death，角色停止
R: 重置角色，方便測試 Death 後回到 Idle
```

Controller 新增的數值：

```text
Move Speed: 水平移動速度
Jump Speed: 跳躍初速度
Gravity: 重力大小
```

目前移動方式是簡單 prototype：

- 水平移動直接改 `node.x`。
- 跳躍直接改 `node.y`。
- `groundY` 會記錄角色一開始的位置，角色落回這個高度時視為著地。
- 還沒有接 Cocos 的剛體、碰撞器或平台判定。

這種做法適合先測角色手感與動畫切換。之後要做正式平台關卡時，可以再改成：

- 加 `RigidBody` / `Collider`。
- 用碰撞判斷是否 grounded。
- 用地板或平台的位置取代固定 `groundY`。
- 把 Attack、Hurt、Death 做成更完整的狀態，避免被移動動畫打斷。
